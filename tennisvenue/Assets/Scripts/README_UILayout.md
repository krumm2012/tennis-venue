# UI面板布局系统使用说明

## 功能概述
这个系统可以将Unity项目中的UI面板重新布局到屏幕左右两侧，清空中间区域，让您更好地观察网球场地和幕布效果。

## 系统组件

### 1. UIPanelLayoutManager.cs
- **主要功能**: 重新安排UI面板位置到左右两侧
- **自动布局**: 启动时自动应用左右布局
- **手动控制**: 支持F13键手动重新布局

### 2. UILayoutTester.cs
- **测试功能**: 验证布局效果和面板位置
- **可视化标记**: 创建测试标记显示布局区域
- **布局报告**: 生成详细的布局状态报告

### 3. CurtainImageQuickSetup.cs
- **集成功能**: 将布局管理器集成到快速设置系统
- **自动应用**: 启动时自动应用左右布局

## 布局效果

### 左侧面板 (Left Control Panel)
- **位置**: 屏幕左侧
- **功能**: 主要控制功能
- **包含按钮**:
  - Launch Ball (发射网球)
  - Reset Game (重置游戏)
  - Clear Balls (清除所有球)
  - Auto Play (自动播放)
  - Swing Test (摇摆测试)
  - Height Analysis (高度分析)

### 右侧面板 (Right Control Panel)
- **位置**: 屏幕右侧
- **功能**: 视角控制功能
- **包含按钮**:
  - Default View (默认视角)
  - Back View (后视视角)
  - Top View (俯视视角)
  - Side View (侧视视角)
  - Close View (近距离视角)
  - Panorama (全景视角)

### 中间区域
- **状态**: 完全清空
- **目的**: 便于观察网球场地和幕布效果
- **优势**: 无UI遮挡，视野开阔

## 使用方法

### 自动应用
系统启动时会自动应用左右布局，无需手动操作。

### 手动控制
- **F13键** - 重新布局面板到左右两侧
- **F14键** - 测试UI布局效果
- **F8键** - 应用附件图片（同时应用布局）

### Inspector右键菜单
在Inspector中右键点击脚本组件，可以使用以下功能：
- "应用左右两侧布局"
- "重置为原始布局"
- "隐藏所有面板"
- "显示所有面板"
- "测试UI布局"
- "创建测试标记"
- "生成布局报告"

## 技术特点

### 自适应布局
- **屏幕适配**: 自动适配不同屏幕尺寸
- **响应式设计**: 根据屏幕分辨率调整面板位置
- **边距控制**: 可调节面板与屏幕边缘的距离

### 面板管理
- **智能定位**: 自动检测和重新定位现有面板
- **尺寸优化**: 统一面板尺寸，保持界面整洁
- **层级管理**: 合理的UI层级和显示顺序

### 兼容性
- **现有UI**: 与现有UI系统完全兼容
- **功能保持**: 所有按钮功能保持不变
- **性能优化**: 高效的布局算法，不影响性能

## 自定义选项

### 面板尺寸
```csharp
public Vector2 leftPanelSize = new Vector2(200, 300);
public Vector2 rightPanelSize = new Vector2(200, 300);
```

### 边距设置
```csharp
public float sideMargin = 20f;    // 左右边距
public float topMargin = 20f;     // 顶部边距
public float panelSpacing = 10f;  // 面板间距
```

### 快捷键设置
```csharp
public KeyCode layoutKey = KeyCode.F13;      // 布局快捷键
public KeyCode testLayoutKey = KeyCode.F14;  // 测试快捷键
```

## 故障排除

### 面板位置不正确
1. 按F13键重新应用布局
2. 检查屏幕分辨率设置
3. 使用F14键测试布局效果

### 中间区域仍有面板
1. 使用"生成布局报告"功能检查
2. 按F13键强制重新布局
3. 检查是否有其他UI系统干扰

### 按钮功能失效
1. 检查UI管理器是否正确初始化
2. 验证按钮事件绑定
3. 重新启动场景

## 最佳实践

### 使用建议
1. **首次使用**: 让系统自动应用布局
2. **调整布局**: 使用F13键重新布局
3. **验证效果**: 使用F14键测试布局
4. **定期检查**: 使用"生成布局报告"监控状态

### 性能优化
1. **避免频繁布局**: 不要在Update中频繁调用布局函数
2. **合理使用测试**: 测试标记会自动销毁，无需手动清理
3. **面板数量控制**: 避免创建过多面板影响性能
