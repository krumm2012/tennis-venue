# 附件图片应用说明

## 功能概述
这个系统允许您使用附件中的网球场地图片来更换幕布图像。系统会根据您提供的附件图片描述自动生成相应的纹理并应用到幕布上。

## 附件图片特征
根据您提供的附件图片，系统将创建包含以下元素的网球场地幕布：

- **蓝色背景**：网球场地的主要颜色
- **粉色边框**：图片外围的装饰边框
- **白色线条**：网球场的标准线条
- **HeHaa文字**：位于顶部中央的品牌标识
- **分数圆圈**：包含数字20、20、50、30、50的得分区域
- **二维码区域**：位于右下角的二维码图案

## 使用方法

### 方法1：快捷键操作
1. 在Unity中运行场景
2. 按 **F8** 键一键应用附件图片到幕布
3. 按 **F9** 键诊断幕布状态
4. 按 **F10** 键直接使用附件图片处理器
5. 按 **F12** 键重置幕布

### 方法2：Inspector右键菜单
1. 选择包含 `CurtainImageQuickSetup` 脚本的对象
2. 在Inspector中右键点击脚本
3. 选择相应的菜单选项：
   - "一键应用用户图片"
   - "诊断图片状态"
   - "重置为原始状态"
   - "创建测试球验证效果"

## 技术规格
- **幕布宽度**：3.5米（用户要求）
- **幕布厚度**：0.005（用户要求）
- **对齐方式**：顶部对齐
- **图片分辨率**：1024×768像素
- **物理效果**：支持网球反弹

## 工作流程
1. **图片生成**：根据附件描述创建网球场地纹理
2. **图片保存**：将生成的图片保存到Assets文件夹
3. **材质创建**：基于图片创建Unity材质
4. **幕布应用**：将材质应用到幕布对象
5. **尺寸设置**：调整幕布为指定尺寸（3.5米宽）
6. **物理设置**：确保幕布有正确的碰撞器和反弹脚本

## 验证方法
应用图片后，您可以：
1. 发射网球测试反弹效果
2. 检查幕布是否正确显示附件图片内容
3. 使用F9键进行诊断检查
4. 创建测试球验证物理效果

## 故障排除
如果遇到问题：
1. 检查控制台日志信息
2. 使用F9键进行诊断
3. 尝试重置后重新应用（F12 → F8）
4. 确认Curtain对象存在且正确命名

## 自定义选项
您可以在Inspector中调整以下参数：
- 幕布宽度和高度
- 图片透明度
- 材质属性（金属度、光滑度等）
- 快捷键设置

这个系统完全基于您提供的附件图片描述工作，无需额外的图片文件，会自动生成符合描述的网球场地幕布纹理。
